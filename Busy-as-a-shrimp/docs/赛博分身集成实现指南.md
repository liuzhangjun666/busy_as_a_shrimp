## 4\.3 龙虾 Skill 定义

Skill 是 DeerFlow 的任务模板，用 Markdown 文件定义。存放路径：/mnt/skills/lobster\-daily\-scan/SKILL\.md

\-\-\-

name: lobster\-daily\-scan

description: 搞钱小龙虾每日自动化扫描，为用户发现商机

tools:

  \- browser\_navigate     \# 来自 OpenClaw MCP

  \- browser\_act

  \- browser\_snapshot

  \- browser\_screenshot

\-\-\-

\# 龙虾每日扫描

你是一个"打工人 Agent"，为搞钱小龙虾的用户执行每日商机扫描。

\#\# 工作流程

1\. \*\*读取用户画像\*\*：调用 GET http://localhost:8081/api/v1/lobster/profile/\{userId\}

   \- 获取用户性格类型（city/ecommerce/global）、城市、偏好标签

2\. \*\*根据性格类型执行不同扫描\*\*：

   \- city（同城型）：在1688搜索同城供应链 → 采集价格区间/联系方式

   \- ecommerce（电商型）：在小红书搜索带货笔记 → 采集佣金信息/爆款数据

   \- global（全网型）：综合以上 \+ 抖音热点数据

3\. \*\*浏览器操作步骤\*\*：

   a\. 使用 browser\_navigate 打开目标平台

   b\. 使用 browser\_snapshot 获取页面结构

   c\. 使用 browser\_act 输入搜索关键词

   d\. 使用 browser\_snapshot 获取结果页

   e\. 从快照中提取数据（标题、价格、链接）

4\. \*\*质量打分\*\*：对每个发现的机会评估

   \- 利润空间 > 30%：高优先级

   \- 佣金率 > 20%：高优先级

   \- 近7天热度上升：加分

5\. \*\*生成内容草稿\*\*：为高优先级机会生成简短的推荐文案

6\. \*\*暂停等待审核\*\*：调用 interrupt\(\) 暂停，等待人工审核

7\. \*\*推送结果\*\*：审核通过后，调用 POST http://localhost:8081/api/v1/lobster/push\-result

   \- 请求头必须带 X\-DeerFlow\-Signature

\#\# 安全限制

\- 仅访问 hostnameAllowlist 中的域名

\- 不采集用户真实联系方式，使用虚拟中继邮箱

\- 所有内容标注"AI辅助生成，仅供参考"

\- 每个用户每日最多扫描 3 个平台

## 5\.6 LobsterModule — HMAC 验证 Guard

新建文件：apps/api/src/modules/lobster/guards/deerflow\-signature\.guard\.ts

DeerFlow 回调 NestJS 时必须带 HMAC\-SHA256 签名，防伪造。

import \{ CanActivate, ExecutionContext, Injectable, UnauthorizedException \} from "@nestjs/common";

import \{ createHmac, timingSafeEqual \} from "crypto";

@Injectable\(\)

export class DeerFlowSignatureGuard implements CanActivate \{

  private readonly secret = process\.env\.DEERFLOW\_CALLBACK\_SECRET ?? "default\_secret";

  canActivate\(context: ExecutionContext\): boolean \{

    const request = context\.switchToHttp\(\)\.getRequest<\{

      headers: \{ "x\-deerflow\-signature"?: string; "x\-deerflow\-timestamp"?: string \};

      body: unknown;

      rawBody?: Buffer;

    \}>\(\);

    const signature = request\.headers\["x\-deerflow\-signature"\];

    const timestamp = request\.headers\["x\-deerflow\-timestamp"\];

    if \(\!signature || \!timestamp\) \{

      throw new UnauthorizedException\("Missing DeerFlow signature headers"\);

    \}

    // 防重放：时间戳不超过 5 分钟

    const age = Date\.now\(\) \- Number\(timestamp\);

    if \(isNaN\(age\) || age > 5 \* 60 \* 1000\) \{

      throw new UnauthorizedException\("DeerFlow signature expired"\);

    \}

    const raw = request\.rawBody ?? Buffer\.from\(JSON\.stringify\(request\.body\)\);

    const expected = createHmac\("sha256", this\.secret\)

      \.update\(\`$\{timestamp\}\.$\{raw\.toString\(\)\}\`\)

      \.digest\("hex"\);

    const sigBuf = Buffer\.from\(signature\);

    const expBuf = Buffer\.from\(expected\);

    if \(sigBuf\.length \!== expBuf\.length || \!timingSafeEqual\(sigBuf, expBuf\)\) \{

      throw new UnauthorizedException\("Invalid DeerFlow signature"\);

    \}

    return true;

  \}

\}
